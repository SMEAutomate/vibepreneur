# Vibepreneur Marketing Videos

Remotion project containing 26 marketing video concepts, each rendered in 9:16 (1080x1920) and 16:9 (1920x1080).

## Setup

```bash
cd remotion
npm install
npm run dev          # opens Remotion Studio
```

## Render

```bash
npx remotion render src/index.ts <composition-id> out/<name>.mp4
```

Composition IDs follow `<video-slug>-16x9` and `<video-slug>-9x16`.
