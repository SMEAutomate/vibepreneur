# Launch Copy Guide

## Voice Principles

1. **Intelligent, not academic.** Write for smart professionals. Skip jargon but do not oversimplify.
2. **Confident, not arrogant.** State what the system does clearly. Let the output speak.
3. **Calm, not quiet.** Premium restraint. No exclamation points. No hype words.
4. **Concrete, not abstract.** Every claim should have a tangible output or example behind it.
5. **Outcome-led.** Lead with what the user gets, not what the system does internally.

## Word Preferences

| Prefer           | Avoid                           |
| ---------------- | ------------------------------- |
| structure        | magic                           |
| execution        | autopilot                       |
| ownership        | passive income                  |
| venture          | side hustle                     |
| operating system | tool / app                      |
| launch-ready     | MVP                             |
| progress         | growth hacking                  |
| traction         | viral                           |
| systems          | hacks                           |
| leverage         | scale (as verb without context) |
| clarity          | disruption                      |
| validated        | proven (unless actually proven) |

## Formatting Rules

- Never use em dashes. Use periods, commas, colons, or parentheses instead.
- Page titles use `|` as separator (e.g. "The System | Vibepreneur")
- Email sign-offs use "The Vibepreneur Team" (no leading dash)
- Hyphens (-) are OK for UI placeholders
- No emojis in marketing copy

## CTA Language

| Context                       | CTA                                   |
| ----------------------------- | ------------------------------------- |
| Primary (hero, end of page)   | Start My Business System              |
| Secondary (mid-page, feature) | See How It Works / Explore this layer |
| Waitlist (conversion point)   | Join the Waitlist                     |
| Pricing                       | Start Free / Join Waitlist: Pro       |

## Headline Patterns

Good:

- "Your experience is already a business. We make it operational."
- "From expertise to ownership."
- "Wake up to progress."
- "What you actually own."

Bad:

- "The ultimate AI business builder!"
- "10x your income with AI!"
- "Build a business while you sleep!"

## Section Copy Structure

Each section should follow:

1. Headline (outcome-focused, max 10 words)
2. Subheadline (1-2 sentences, explains the mechanism)
3. Content (cards, lists, visuals showing tangible outputs)
4. Optional CTA (only if section warrants one)

Keep sections focused. One idea per section. If it needs more than 3 paragraphs, it should be its own page.
