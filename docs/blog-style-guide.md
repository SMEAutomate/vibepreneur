# Blog Style Guide

## Tone

- Editorial and strategic, not casual or motivational
- Written for smart professionals, not a broad internet audience
- Confident without being preachy
- Direct without being aggressive
- Commercially literate without being salesy

## Formatting Rules

- Use `##` subheadings to break up long posts (no `#` H1 in body)
- No em dashes. Use periods, commas, colons, or parentheses.
- Paragraphs stored as string arrays in `body[]`
- Subheadings included inline as `"## Heading"` strings in the body array
- Include a `pullquote` that captures the most quotable insight
- Add `steps` or `comparison` when the content supports a structured visual
- Target 1,000-1,800 words per post
- Include `readTime` estimated at ~220 words per minute

## Visual Rules

- Every post uses a `BlogThumbnailVariant` from the 24 available animated SVG thumbnails
- Choose thumbnails that match the post concept:
  - Process/timeline: `timeline-march`, `calendar-check`
  - Growth/scale: `rising-bars`, `ladder-steps`, `arrow-bounce`
  - Systems: `node-network`, `gear-turn`, `orbit-rings`
  - Decision/direction: `split-path`, `filter-funnel`, `crossroads-pause`
  - Trust/quality: `shield-glow`, `stack-build`

## CTA Patterns

- End-of-article CTA block is handled by the article template (not embedded in body)
- For mid-article CTAs, reference Vibepreneur naturally within the content
- Link to relevant site pages (the-system, how-it-works, daily-brief, waitlist)
- Use calm, outcome-focused CTA language:
  - "See how Vibepreneur structures this"
  - "Explore the venture operating system"
  - "Join the early access waitlist"
  - "Build from what you already know"

## Word Preferences

| Prefer           | Avoid                           |
| ---------------- | ------------------------------- |
| structured       | magic                           |
| execution        | autopilot                       |
| ownership        | passive income                  |
| venture          | side hustle                     |
| operating system | tool / app                      |
| launch-ready     | MVP                             |
| progress         | growth hacking                  |
| traction         | viral                           |
| systems          | hacks                           |
| leverage         | hustle                          |
| validated        | proven (unless actually proven) |

## Categories

- **From Experience to Business**: How expertise becomes a product or service
- **Venture Systems**: The operating system approach to business building
- **Validation & Launch**: Structured approaches to testing and shipping
- **Career Pivot**: Transitioning from employment to ownership (legacy)
- **Building**: Hands-on construction of businesses (legacy)
- **Mindset**: Mental models for professional builders (legacy)

## Internal Linking

Each post should naturally reference at least:

- One other blog post (related topic)
- One site page (/the-system, /how-it-works, /daily-brief, /pricing)
- The waitlist as a natural next step for interested readers

## Slug Convention

Use lowercase kebab-case. Keep slugs concise but descriptive. Maximum 6-7 words.
